## Third-Party Code 

| Package | Why it was chosen |
|---------|--------------------|
| `next` | Provides a full-stack framework with React and built-in API routes in one project. |
| `react` / `react-dom` | Used by Next.js to build and render the application's user interface. |
| `typescript` | Adds static type checking to catch errors before runtime. |
| `better-sqlite3` | Provides a fast, simple SQLite database with no separate server required. |
| `@types/better-sqlite3` | Adds TypeScript type definitions for `better-sqlite3`. |
| `vitest` | Fast testing framework used to write and run automated tests. |
| `tailwindcss` | Utility-first CSS framework for quickly styling the application. |
| `eslint` | Detects code quality and style issues during development. |
